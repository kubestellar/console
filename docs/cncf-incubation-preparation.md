# CNCF Incubation Preparation Plan (Q4 2026)

**Target:** Submit CNCF incubation application to TOC in **October 2026**
**Primary issues:** [#18773](https://github.com/kubestellar/console/issues/18773), [#18783](https://github.com/kubestellar/console/issues/18783), [#18813](https://github.com/kubestellar/console/issues/18813)
**Related issues:** [#18691](https://github.com/kubestellar/console/issues/18691), [#18746](https://github.com/kubestellar/console/issues/18746)

## Executive summary

This plan organizes Q4 2026 work needed to convert current momentum into a complete CNCF incubation evidence package. The focus is to: (1) strengthen production-adoption proof, (2) increase and document human community participation, (3) formalize governance artifacts, and (4) mature published security evidence before October TOC submission.

## 3) Community evidence package

### 3.1 Production adopters strategy

1. Maintain a tiered adopter model (public reference, private confirmation, technical validation).
2. Obtain at least **5 publishable production references** by September.
3. Keep each adopter entry linked to validation artifacts and contact confirmation date.

### 3.2 Human contributor ratio target

| Metric | Baseline | Target by Sep 2026 | Tracking |
| --- | ---: | ---: | --- |
| Human-authored merged PR ratio | In progress | **≥60%** | Monthly GitHub export |
| New human contributors / quarter | In progress | **+20% QoQ** | Quarterly review |
| Median maintainer response time | Active | Maintain or improve | Monthly issue/PR metrics |

### 3.3 Governance documentation package

| Document | Status | Gap |
| --- | --- | --- |
| Community roles and responsibilities | Partial | Consolidate into a CNCF-facing summary |
| Decision-making process | Partial | Add explicit decision-log index |
| Escalation and conflict resolution | Partial | Publish maintainership escalation procedure |

## 6) Dependencies, risks, and mitigations

| Risk | Impact | Mitigation |
| --- | --- | --- |
| Insufficient public production references | High | Start outreach now; accept tiered evidence while seeking public approvals |
| Contributor-ratio volatility | Medium | Increase mentorship/review bandwidth for external contributors |
| Governance docs lag | Medium | Assign single owner and weekly review checkpoints |
| Security evidence delays | High | Pre-book audit window and track checklist weekly |
