- Added bounded Prometheus metrics for the auth rate-limit tracker and JWT revocation cache (`pkg/api/middleware/metrics.go`): `console_auth_rate_limit_failures_total{tier}`, `console_auth_rate_limit_tracked_keys`, `console_auth_rate_limit_purged_total`, `console_auth_token_revocations_total`, `console_auth_revoked_tokens_cache_size`, and `console_auth_revoked_tokens_evicted_total{reason}`. Both `FailureTracker` (login brute-force throttling) and `revokedTokenCache` (JWT revocation) previously only logged via `slog`, so there was no way to see failure pressure trending toward a hard-lock or revocation-cache growth approaching its cap without grepping logs.
