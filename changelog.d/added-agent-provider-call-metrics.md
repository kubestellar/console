- Added bounded Prometheus metrics for AI agent provider calls made through the console agent registry (`pkg/agent/registry.go`, `pkg/agent/metered_provider.go`): `console_agent_provider_calls_total{provider,operation,result}` and `console_agent_provider_call_duration_seconds{provider,operation}`, covering `chat`, `stream_chat`, and `stream_chat_progress`. Every `ai.Provider` registered via `Registry.Register` (claude-code, codex, ollama, groq, etc. — a fixed, code-defined set) is now wrapped once at registration, so calls made through any of the several call sites in `server_ai_chat.go`, `server_ai_chat_stream.go`, `server_ai_mixed.go`, and `pkg/agent/workers` are measured uniformly. These calls previously had zero metrics, unlike `pkg/kagentiprovider` and `pkg/stellar/providers`.
