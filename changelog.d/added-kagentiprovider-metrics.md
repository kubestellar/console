- Added bounded Prometheus metrics for the Kagenti A2A/controller client (`pkg/kagentiprovider/client.go`): `console_kagenti_calls_total{operation,result}` and `console_kagenti_call_duration_seconds{operation}`, covering `status`, `list_agents`, `discover`, and `invoke`. Previously this client only logged read failures via `slog` and had no counter or latency metric, unlike the sibling `pkg/kagent` client.
