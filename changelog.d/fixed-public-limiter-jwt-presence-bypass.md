- Fixed a rate-limit bypass in `pkg/api/routes_auth.go`: the exemption from the per-IP public rate limiter checked only whether an `Authorization: Bearer ...` header or `kc_auth` cookie was present, not whether the JWT it carried was valid. Since the public route group (`publicAPI`) never runs `jwtAuth`/`apiLimiter`, an unauthenticated client could bypass the 120 req/min/IP limit entirely by sending an arbitrary header or cookie value. The check now verifies the token signature via `middleware.ParseJWT` before granting the exemption.
